# 📖 Recetas

Nuestro recetario completo con más de 23 recetas organizadas por categoría. Encuentra tus platos favoritos y descubre nuevas opciones culinarias.

## Categorías

### 🥂 [Aperitivos y Entrantes](aperitivos-y-entrantes/README.md)
Deliciosas opciones para comenzar tus comidas. Desde aperitivos para ocasiones especiales hasta entrantes que preparan el camino para el plato principal.

### 🥗 [Ensaladas y Verduras](ensaladas-y-verduras/README.md)
Opciones frescas y saludables con ingredientes vegetales. Perfectas para complementar cualquier comida o como plato ligero.

### 🍲 [Sopas, Cremas y Caldos](sopas-cremas-y-caldos/README.md)
Platos reconfortantes y nutritivos. Ideales para cualquier estación del año.

### 🍽️ [Platos Principales](platos-principales/README.md)
Las recetas más completas y satisfactorias. Desde arroces y pastas hasta carnes y pescados, aquí encontrarás opciones para todos los gustos.

### 🥘 [Guarniciones](guarniciones/README.md)
Acompañamientos y platos de apoyo. Ideales para complementar tus platos principales o servir como plato secundario.

### 🍰 [Postres](postres/README.md)
Dulces y sabrosas opciones para terminar tus comidas. Desde postres clásicos hasta alternativas modernas.
