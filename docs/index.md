# Recetario personal

Bienvenido a tu recetario personal. Aquí encontrarás recetas organizadas por categorías para cocinar de forma sencilla y mantener una colección clara y útil.

## Últimas categorías

- [Entradas](recetas/entradas/README.md)
- [Principales](recetas/principales/README.md)
- [Postres](recetas/postres/README.md)

## Cómo mantenerlo

- Crea una nueva receta como un archivo Markdown en la categoría correspondiente.
- Usa la plantilla de receta para mantener un formato uniforme.
- Añade imágenes solo si quieren acompañar la receta.
- El sitio se encargará de mostrar y organizar el contenido automáticamente.
