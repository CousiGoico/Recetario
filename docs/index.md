# Recetario personal

Bienvenido a tu recetario personal. Aquí encontrarás más de 23 recetas organizadas por categorías para cocinar de forma sencilla y mantener una colección clara y útil.

## Categorías principales

- 🥗 [Ensaladas y Verduras](recetas/ensaladas-y-verduras/README.md)

- 🥘 [Guarniciones](recetas/guarniciones/README.md)

## Cómo mantenerlo

- Crea una nueva receta como un archivo Markdown en la categoría correspondiente.
- Usa la plantilla de receta para mantener un formato uniforme.
- Añade imágenes solo si quieren acompañar la receta.
- El sitio se encargará de mostrar y organizar el contenido automáticamente.
